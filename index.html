Bab 1 — Apa itu Python?

Sebelum mulai ngoding, kenalan dulu yuk sama Python — bahasa pemrograman yang bakal jadi teman belajar kita.

1.1 Penjelasan Python

Python adalah bahasa pemrograman tingkat tinggi yang dibuat oleh Guido van Rossum dan pertama kali dirilis pada tahun 1991. Python dirancang supaya kodenya gampang dibaca — bahkan mirip seperti kalimat bahasa Inggris biasa!

Kenapa Python jadi salah satu bahasa pemrograman paling populer di dunia?

  • Sintaksnya sederhana dan mudah dipahami, cocok banget buat pemula.
  • Serbaguna — bisa dipakai untuk membuat website, aplikasi, game, sampai kecerdasan buatan (AI).
  • Komunitasnya besar, jadi kalau ketemu masalah gampang cari solusinya.
  • Dipakai oleh perusahaan-perusahaan besar seperti Google, Instagram, Spotify, dan NASA.
Catatan tutor: kalau bahasa pemrograman lain kadang berasa kayak nulis mantra yang ribet, Python itu lebih mirip nulis resep masakan — instruksinya jelas, urut, dan gampang diikuti. Komputer tinggal "memasak" instruksi itu jadi program yang beneran jalan.
🤔   Tau nggak, kenapa namanya "Python"?  (klik buat lihat jawabannya)
😄  Ternyata bukan dari nama ular! Guido van Rossum menamainya dari acara komedi favoritnya, Monty Python's Flying Circus. Jadi namanya itu lucu-lucuan, bukan galak kayak ularnya.

1.2 Format Penyimpanan File Python

Setiap file kode Python disimpan dengan ekstensi .py — contohnya latihan_pertama.py atau belajar_python.py.

Kenapa ekstensi ini penting?

  • Supaya text editor (seperti VS Code) tahu ini file Python, jadi bisa mengaktifkan syntax highlighting (pewarnaan kode) dan autocomplete.
  • Supaya komputer tahu file ini harus dijalankan pakai Python interpreter.

Aturan penamaan file yang baik:

  • Gunakan huruf kecil semua.
  • Kalau lebih dari satu kata, pisahkan dengan underscore _, bukan spasi.
  • Jangan diawali dengan angka.

Bab 2 — Apa itu Python Extension?

Nulis kode Python bakal jauh lebih nyaman kalau pakai text editor yang tepat, lengkap dengan "senjata tambahan" bernama extension.

2.1 Penjelasan Extension

Untuk menulis kode Python, kita butuh sebuah text editor atau IDE (Integrated Development Environment). Salah satu yang paling direkomendasikan untuk pemula adalah Visual Studio Code (VS Code) — gratis, ringan, dan sangat populer di kalangan programmer.

Nah, extension itu semacam aplikasi tambahan yang bisa dipasang di VS Code untuk menambah fitur — mirip seperti kamu meng-install aplikasi tambahan di HP supaya makin canggih.

Extension "Python" dari Microsoft memberikan fitur-fitur seperti:

  • 🎨 Syntax highlighting — kode jadi berwarna-warni dan gampang dibaca.
  • 💡 IntelliSense — bantuan autocomplete cerdas saat mengetik kode.
  • 🐞 Debugging — membantu menemukan dan membenarkan kesalahan di kode.
  • ▶️ Run Code — bisa langsung menjalankan kode Python dari dalam editor.

2.2 Instalasi Extension

Bab 3 — Python String Print

Saatnya menulis kode Python pertamamu! Kita mulai dari yang paling seru: menampilkan teks di layar.

3.1 Penjelasan String Print

String adalah kumpulan karakter atau teks yang diapit oleh tanda kutip satu ' ' atau tanda kutip dua " ". Contohnya: "Halo, Dunia!" atau 'Aku belajar Python'.

Untuk menampilkan teks ke layar, Python punya fungsi bawaan bernama print(). Formatnya seperti ini:

contoh.py
print("Halo, Dunia!")
# Hasil (output): Halo, Dunia!

Kamu bisa pakai tanda kutip satu maupun dua, hasilnya sama saja:

contoh.py
print('Selamat belajar Python!')
💡 Setiap print() otomatis pindah ke baris baru untuk print() berikutnya — makanya kalau kamu tulis dua print(), hasilnya akan tampil di dua baris terpisah.

Bab 4 — Python Multiline String Print

Gimana caranya kalau kita mau print teks yang panjangnya berbaris-baris? Yuk cari tahu triknya.

4.1 Penjelasan Multiline Print

Kalau teks yang mau ditampilkan cuma satu baris, tanda kutip biasa sudah cukup. Tapi kalau teksnya panjang dan perlu beberapa baris, kita bisa pakai triple quotes: tiga tanda kutip berturut-turut, baik ''' ''' maupun """ """.

cerita.py
print("""
Halo, namaku Python!
Aku suka membantu manusia menulis program.
Yuk belajar bareng!
""")

Triple quotes ini sering dipakai untuk:

  • Menulis paragraf panjang.
  • Membuat puisi atau surat.
  • Menulis dokumentasi / catatan penjelasan di dalam kode.
Catatan tutor: perhatikan baris kosong di atas dan bawah tulisan — itu karena Python mencetak persis apa yang ada di antara tanda kutip triple-nya, termasuk baris kosongnya!

Bab 5 — Python Math Operational

Ternyata Python bukan cuma jago nulis teks — dia juga jago berhitung. Yuk kita coba pakai Python sebagai kalkulator!

5.1 Python Math Operational Explanation

Inget di Bab 3, kita lihat kalau print("5 + 3") hasilnya teks 5 + 3 — itu karena angkanya diapit tanda kutip, jadi dianggap string. Nah, kalau tanda kutipnya kita hilangkan, Python beneran akan menghitungnya!

kalkulator.py
print(5 + 3)
# Hasil (output): 8

Beberapa operator matematika yang bisa dipakai:

  • + tambah — print(5 + 3) → 8
  • - kurang — print(10 - 4) → 6
  • * kali — print(6 * 7) → 42
  • / bagi — print(20 / 4) → 5.0
  • // bagi bulat (floor division) — print(17 // 5) → 3
  • % sisa bagi (modulus) — print(17 % 5) → 2
  • ** pangkat — print(2 ** 3) → 8
💡 Hasil pembagian ( / ) di Python SELALU berupa desimal (float), walaupun hasilnya bulat. Makanya 20 / 4 hasilnya 5.0, bukan 5.
Catatan tutor: tanda kurung ( ) tetap bisa dipakai buat ngatur urutan operasi, sama seperti matematika biasa — yang di dalam kurung dikerjakan duluan.

Bab 6 — Python Comment

Kadang kita perlu ninggalin catatan kecil di dalam kode. Yuk kenalan sama comment.

6.1 Python Comment Explanation

Comment adalah catatan di dalam kode yang tidak ikut dijalankan oleh Python — isinya cuma buat dibaca manusia, bukan buat diproses komputer.

Cara membuatnya gampang: taruh tanda pagar # di awal baris, atau di belakang kode.

catatan.py
# Ini komentar, tidak akan muncul di output
print("Halo!") # Ini juga komentar, ditulis di belakang kode

Kenapa comment berguna?

  • Membantu menjelaskan maksud kode buat diri sendiri atau orang lain yang baca nanti.
  • Bisa dipakai buat "mematikan sementara" satu baris kode tanpa perlu menghapusnya — biasanya buat coba-coba/testing.
💡 Comment sama sekali tidak memengaruhi jalannya program. Python bakal melewatinya begitu saja.
