Bab 12 — Percabangan (If/Elif/Else)

Program jadi punya "otak" — bisa mengambil keputusan berdasarkan kondisi tertentu.

12.1 Penjelasan If/Elif/Else

Percabangan memungkinkan program menjalankan blok kode yang berbeda tergantung kondisi. Struktur dasarnya:

  • if kondisi: — jika kondisi bernilai True, jalankan blok ini.
  • elif kondisi: — jika kondisi if salah, cek kondisi ini (bisa banyak).
  • else: — jika semua kondisi di atas salah, jalankan blok ini.

Operator perbandingan: ==, !=, >, <, >=, <=.

Operator logika: and, or, not.

contoh.py
nilai = 85
if nilai >= 75:
    print("Lulus!")
elif nilai >= 50:
    print("Perbaikan")
else:
    print("Tidak Lulus")

Bab 13 — Perulangan (Loop)

Menjalankan perintah berulang kali tanpa capek. Jantung dari otomatisasi.

13.1 Penjelasan For & While

  • for i in range(n): — ulangi blok sebanyak n kali.
  • while kondisi: — ulangi blok SELAGI kondisi bernilai True.
  • break — keluar dari loop paksa.
  • continue — loncat ke iterasi berikutnya.
loop.py
# For loop
for i in range(5):
    print("Halo ke-", i+1)

# While loop
x = 0
while x < 3:
    print("x =", x)
    x = x + 1

Bab 14 — Fungsi (Function)

Membungkus kode ke dalam blok yang bisa dipanggil berkali-kali. Kode jadi rapi dan modular.

14.1 Penjelasan Fungsi

Fungsi adalah blok kode yang punya nama, bisa menerima parameter, dan mengembalikan nilai (return).

fungsi.py
def sapa(nama):
    return "Halo " + nama

print(sapa("Andi"))

Manfaat fungsi:

  • Menghindari duplikasi kode.
  • Memudahkan debugging.
  • Membuat program lebih terstruktur.

Bab 15 — Dictionary & Set

Menyimpan data dengan struktur yang lebih bermakna: pasangan kunci-nilai (dict) dan kumpulan unik (set).

15.1 Penjelasan Dict & Set

Dictionary dict menyimpan data dalam pasangan key-value. Setiap key bersifat unik.

dict.py
kontak = {
    "Andi": "08123456789",
    "Budi": "08198765432"
}
print(kontak["Andi"])
kontak["Citra"] = "08999999999"  # Tambah data
print(kontak.keys())

Set set adalah kumpulan nilai unik (tanpa duplikat).

set.py
nilai_unik = {1, 2, 3, 3, 4}
print(nilai_unik)  # {1, 2, 3, 4}
nilai_unik.add(5)
print(nilai_unik)

Bab 16 — File Handling

Menyimpan data secara permanen ke file, sehingga tidak hilang saat program ditutup.

16.1 Penjelasan File Handling

Di Python, kita menggunakan fungsi open() untuk membuka file.

  • open("file.txt", "r") — baca (read).
  • open("file.txt", "w") — tulis (write) — menimpa isi file.
  • open("file.txt", "a") — tambah (append) di akhir file.
  • Best practice: gunakan with open(...) as f: agar file otomatis ditutup.
file.py
# Menyimpan data
with open("catatan.txt", "w") as f:
    f.write("Halo dari Python!\n")

# Membaca data
with open("catatan.txt", "r") as f:
    isi = f.read()
    print(isi)
Catatan tutor: Di simulator ini, file disimulasikan menggunakan localStorage agar tetap bisa dicoba di browser. Jadi file akan tetap ada meskipun halaman di-refresh.

Bab 17 — Error Handling (Try/Except)

Program profesional tidak akan crash hanya karena user salah input. Kita bisa menangkap error dengan try/except.

17.1 Penjelasan Try/Except

  • try: — blok kode yang mungkin menimbulkan error.
  • except: — blok yang dijalankan jika terjadi error.
  • except NamaError: — tangkap error spesifik (misal: ValueError).
  • else: — dijalankan jika tidak ada error.
  • finally: — selalu dijalankan, entah error atau tidak.
error.py
try:
    angka = int(input("Masukkan angka: "))
    print("Angka:", angka)
except ValueError:
    print("Error: kamu harus memasukkan angka!")
💡 Error handling membuat program lebih ramah pengguna. Daripada muncul pesan error merah, kita bisa memberi tahu user dengan kalimat yang jelas.
