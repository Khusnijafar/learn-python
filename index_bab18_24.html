Bab 18 — Class & Object (OOP)

Object-Oriented Programming (OOP) adalah paradigma yang memodelkan dunia nyata ke dalam class dan object.

18.1 Pengenalan Class

Class adalah cetak biru (blueprint) untuk membuat objek. Object adalah instance dari class.

  • class NamaClass: — mendefinisikan class.
  • __init__(self, ...) — constructor, dipanggil saat objek dibuat.
  • self — merujuk ke instance itu sendiri.
  • Atribut — variabel yang dimiliki objek.
  • Method — fungsi yang dimiliki objek.
class.py
class Mahasiswa:
    def __init__(self, nama, nim):
        self.nama = nama
        self.nim = nim

    def perkenalan(self):
        return f"Halo, saya {self.nama} ({self.nim})"

andi = Mahasiswa("Andi", "12345")
print(andi.perkenalan())

Bab 19 — Inheritance & Polymorphism

Inheritance memungkinkan class mewarisi atribut dan method dari class lain. Polymorphism memungkinkan method yang sama memiliki perilaku berbeda di class berbeda.

19.1 Penjelasan Inheritance

  • class Anak(Ibu): — Anak mewarisi dari Ibu.
  • super().__init__(...) — memanggil constructor parent.
  • Polymorphism: method yang sama (misal suara()) diimplementasikan berbeda di tiap child class.
inheritance.py
class Hewan:
    def __init__(self, nama):
        self.nama = nama
    def suara(self):
        return "..."

class Kucing(Hewan):
    def suara(self):
        return "Meong!"

class Anjing(Hewan):
    def suara(self):
        return "Guk Guk!"

Bab 20 — Lambda, Map, Filter, Reduce

Lambda adalah fungsi anonim satu baris. Map, Filter, Reduce adalah fungsi untuk memproses data secara fungsional.

20.1 Penjelasan Lambda & Friends

  • lambda x: x * 2 — fungsi yang menggandakan input.
  • map(fungsi, iterable) — terapkan fungsi ke setiap elemen.
  • filter(fungsi, iterable) — ambil elemen yang memenuhi kondisi.
  • reduce(fungsi, iterable) — reduksi menjadi satu nilai (dari functools).
lambda.py
angka = [1, 2, 3, 4, 5]
# Map: kuadrat setiap angka
kuadrat = list(map(lambda x: x**2, angka))
print(kuadrat)  # [1, 4, 9, 16, 25]

# Filter: ambil angka genap
genap = list(filter(lambda x: x % 2 == 0, angka))
print(genap)  # [2, 4]

Bab 21 — Generator & Iterator

Generator adalah fungsi yang menghasilkan nilai satu per satu menggunakan yield. Lebih hemat memori daripada list.

21.1 Penjelasan Generator

  • yield — mengembalikan nilai, tapi fungsi tetap "hidup".
  • next(gen) — mengambil nilai berikutnya.
  • Generator bisa di-loop dengan for.
generator.py
def countdown(n):
    while n > 0:
        yield n
        n -= 1

for i in countdown(5):
    print(i)

Bab 22 — Decorators

Decorator adalah fungsi yang membungkus fungsi lain untuk menambah perilaku tanpa mengubah kode aslinya.

22.1 Penjelasan Decorator

  • Decorator menerima fungsi sebagai argumen.
  • Mengembalikan fungsi baru (wrapper).
  • Ditulis dengan @decorator di atas fungsi.
decorator.py
def sapa(func):
    def wrapper(*args, **kwargs):
        print("Halo sebelum fungsi")
        result = func(*args, **kwargs)
        print("Halo setelah fungsi")
        return result
    return wrapper

@sapa
def nama_saya():
    print("Saya Andi")

nama_saya()

Bab 23 — Working with JSON

JSON adalah format pertukaran data yang paling populer. Python punya modul json untuk membaca dan menulis JSON.

23.1 Penjelasan JSON

  • json.dumps(obj) — ubah Python object ke string JSON.
  • json.loads(str) — ubah string JSON ke Python object.
  • json.dump(obj, file) — tulis JSON ke file.
  • json.load(file) — baca JSON dari file.
json.py
import json

data = {
    "nama": "Andi",
    "umur": 20,
    "hobi": ["coding", "membaca"]
}

json_str = json.dumps(data)
print(json_str)

obj = json.loads(json_str)
print(obj["nama"])

Bab 24 — Database (SQLite Simulation)

Database menyimpan data secara terstruktur. Di simulator ini, kita menggunakan SQLite yang disimulasikan dengan localStorage untuk kemudahan di browser.

24.1 Penjelasan Database

  • SQLite adalah database ringan berbasis file.
  • Operasi dasar: CREATE TABLE, INSERT, SELECT, UPDATE, DELETE.
  • Di simulator ini, kita menggunakan sqlite3 yang disimulasikan.
database.py
import sqlite3

conn = sqlite3.connect("buku.db")
cursor = conn.cursor()
cursor.execute('''CREATE TABLE IF NOT EXISTS buku
    (id INTEGER PRIMARY KEY, judul TEXT, penulis TEXT)''')

cursor.execute("INSERT INTO buku (judul, penulis) VALUES (?, ?)", ("Python 101", "Andi"))
conn.commit()

cursor.execute("SELECT * FROM buku")
print(cursor.fetchall())

conn.close()
Catatan tutor: Di simulator ini, database disimpan di localStorage dengan prefix simdb_. Semua tabel dan data akan tetap ada meskipun halaman di-refresh.
