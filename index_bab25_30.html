Bab 25 — Pengenalan Flask

Flask adalah framework web Python yang ringan dan fleksibel. Cocok banget buat pemula yang mau bikin website atau API.

25.1 Apa itu Flask?

Flask adalah micro-framework untuk membuat aplikasi web dengan Python. Disebut "micro" karena intinya sangat kecil, tapi bisa diperluas dengan banyak ekstensi.

Kenapa Flask cocok untuk pemula?

  • Sintaksnya sederhana dan mudah dipahami.
  • Tidak memaksa struktur folder tertentu — kamu bebas mengatur.
  • Cocok untuk belajar konsep web dasar: routing, request, response.
  • Bisa dipakai untuk membuat REST API dengan cepat.

Struktur project Flask minimal:

📁 my_flask_app/
├── app.py  ← kode utama
├── 📁 templates/  ← file HTML
└── 📁 static/  ← CSS, JS, gambar

Instalasi Flask:

terminal
pip install flask
Catatan tutor: Flask tidak bisa dijalankan langsung di browser seperti Python biasa. Tapi di modul ini, kita punya simulator server Flask — kamu bisa tulis route, lalu "kirim request" dan lihat response-nya!

25.2 Route Pertama

Kode Flask paling sederhana:

app.py
from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "Halo, Dunia!"

if __name__ == "__main__":
    app.run(debug=True)

Penjelasan:

  • @app.route("/") — dekorator yang menandai URL /.
  • def home(): — fungsi yang dijalankan saat URL diakses.
  • return "..." — respons yang dikirim ke browser.
  • Parameter <nama> di route = variabel dinamis.

Bab 26 — Templates (Jinja2)

Daripada menulis HTML di dalam Python, kita pisahkan ke file template terpisah. Flask menggunakan Jinja2 untuk render dinamis.

26.1 Apa itu Template?

Template adalah file HTML dengan placeholder khusus yang bisa diisi data dari Python. Flask menggunakan engine Jinja2.

Sintaks dasar Jinja2:

  • {{ variabel }} — menampilkan nilai variabel.
  • {% if kondisi %} ... {% endif %} — percabangan.
  • {% for item in items %} ... {% endfor %} — perulangan.
  • {# komentar #} — komentar.

Fungsi render_template() digunakan untuk merender file template:

app.py
from flask import Flask, render_template

app = Flask(__name__)

@app.route("/")
def home():
    return render_template("index.html", nama="Andi", umur=17)
templates/index.html
<!DOCTYPE html>
<html>
<body>
    <h1>Halo, {{ nama }}!</h1>
    <p>Umur kamu: {{ umur }} tahun</p>
</body>
</html>

Bab 27 — Form & Method (GET/POST)

Form memungkinkan user mengirim data ke server. Ada dua method utama: GET (data di URL) dan POST (data di body).

27.1 GET vs POST

Aspek GET POST
Data di URL (query string) Body request
Terlihat? Ya Tidak
Untuk Ambil data Kirim data
Method di Flask request.args.get('k') request.form.get('k')

Untuk menerima POST, tambahkan methods=["POST"] di decorator:

app.py
@app.route("/login", methods=["GET", "POST"])
def login():
    if request.method == "POST":
        nama = request.form.get("nama")
        return f"Selamat datang, {nama}!"
    return "Silakan isi form."

27.2 Form Handling

Di simulator ini, kamu bisa mengirim data POST dengan menambahkan query string ke URL. Contoh: /login?nama=Andi akan dianggap sebagai form data nama=Andi.

Bab 28 — REST API (JSON)

REST API adalah cara aplikasi berkomunikasi lewat HTTP. Response-nya berformat JSON — bukan HTML.

28.1 Apa itu REST API?

REST API menggunakan HTTP method yang bermakna:

  • GET — mengambil data
  • POST — membuat data baru
  • PUT — mengubah data
  • DELETE — menghapus data

Response biasanya berbentuk JSON, bukan HTML. Di Flask, gunakan jsonify() untuk mengubah dictionary menjadi JSON.

api.py
from flask import Flask, jsonify

app = Flask(__name__)

@app.route("/api/halo")
def api_halo():
    return jsonify({"pesan": "Halo!", "status": 200})

@app.route("/api/user/<nama>")
def api_user(nama):
    return jsonify({"nama": nama, "aktif": True})

Bab 29 — Database di Flask

Data penting harus disimpan di database, bukan di list sementara. Kita pakai SQLAlchemy sebagai ORM.

29.1 SQLAlchemy Dasar

ORM (Object-Relational Mapping) memungkinkan kita berinteraksi dengan database pakai Python class, tanpa menulis SQL manual.

models.py
from flask_sqlalchemy import SQLAlchemy

db = SQLAlchemy()

class Buku(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    judul = db.Column(db.String(100))
    penulis = db.Column(db.String(50))

Operasi CRUD dengan SQLAlchemy:

  • Create: db.session.add(obj); db.session.commit()
  • Read: Buku.query.all() atau Buku.query.get(id)
  • Update: ubah atribut, lalu db.session.commit()
  • Delete: db.session.delete(obj); db.session.commit()
Catatan: Di simulator ini, database disimulasikan dengan localStorage. API SQLAlchemy-nya disederhanakan agar bisa dijalankan di browser.

29.2 CRUD via API

Simulator berikut sudah menyediakan db.session yang mendukung add, commit, delete, dan query.all().

Bab 30 — Deployment

Saatnya aplikasi Flask kamu online dan bisa diakses siapa saja lewat internet!

30.1 Deploy ke Internet

Beberapa platform gratis untuk deploy Flask:

  • Render — paling mudah, gratis, support Flask langsung.
  • PythonAnywhere — khusus Python, cocok untuk pemula.
  • Railway — modern, cepat, ada free tier.
  • Vercel — lebih cocok untuk serverless functions.
  • Heroku — pernah populer, sekarang berbayar.

Langkah umum deploy ke Render:

1
Push kode ke GitHubBuat repository baru, lalu upload folder project Flask kamu.
2
Buat file requirements.txtIsi dengan daftar library: flask, gunicorn, dll.
3
Buat file ProcfileIsi: web: gunicorn app:app (menggantikan app.run()).
4
Daftar di RenderBuat akun gratis di render.com, lalu connect ke GitHub.
5
Deploy!Pilih repository, atur build command, klik Deploy. Tunggu 2–5 menit.
6
Akses URL-muKamu akan dapat URL seperti nama-app.onrender.com.

30.2 Checklist Deployment

File requirements.txt sudah dibuatMinimal berisi flask dan gunicorn.
Procfile sudah dibuatIsi: web: gunicorn app:app
app.run() hanya dipanggil jika __name__ == "__main__"Jangan hardcode app.run() di production.
Folder templates/ dan static/ sudah di-commitJangan lupa, ini sering kelewat!
Environment variable untuk secret keyJangan hardcode password atau API key di kode.
Sudah dites di localPastikan semua route berjalan sebelum deploy.
💡 Setelah deploy, setiap kali kamu push ke GitHub, Render akan otomatis rebuild dan redeploy aplikasimu. Ini disebut CI/CD.
