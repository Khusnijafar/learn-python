Bab 31 — HTML & CSS untuk Flask

Sebelum halaman web terlihat cantik, kita perlu memahami struktur HTML dan cara styling dengan CSS.

31.1 Struktur HTML5

Setiap halaman HTML modern mengikuti struktur dasar berikut:

index.html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Judul Halaman</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <header>Header website</header>
    <main>Konten utama</main>
    <footer>Footer</footer>
</body>
</html>

Tag HTML yang penting untuk dipahami:

<div>Wadah umum untuk mengelompokkan elemen.
<h1> … <h6>Judul dengan tingkat kepentingan berbeda.
<p>Paragraf teks.
<a href="…">Link ke halaman lain.
<img src="…">Menampilkan gambar.
<ul> / <ol>List tidak berurut / berurut.

CSS Selector Dasar:

  • .kelas — memilih elemen dengan class="kelas".
  • #id — memilih elemen dengan id="id".
  • tag — memilih semua elemen dengan tag tersebut.

Bab 33 — Session & Authentication

Session memungkinkan server "mengingat" siapa yang sedang login. Kita juga bahas cara mengamankan password.

33.1 Session Dasar

Session adalah data yang disimpan di sisi server untuk setiap user. Di Flask, session diakses lewat objek session (mirip dictionary).

app.py
from flask import Flask, session, redirect, url_for

app = Flask(__name__)
app.secret_key = "rahasia-super-aman"

@app.route("/login")
def login():
    session["user"] = "Andi"
    return "Login berhasil!"

@app.route("/dashboard")
def dashboard():
    if "user" not in session:
        return "Kamu belum login!"
    return f"Halo, {session['user']}"

@app.route("/logout")
def logout():
    session.pop("user", None)
    return "Logout berhasil."
Catatan: secret_key wajib di-set supaya session bisa dienkripsi. Jangan pernah hardcode di production — pakai environment variable!

33.2 Login & Logout

Pola umum login:

auth.py
from werkzeug.security import generate_password_hash, check_password_hash

# Saat registrasi:
hashed = generate_password_hash("password123")

# Saat login:
if check_password_hash(hashed, input_password):
    session["user"] = username
    return redirect(url_for("dashboard"))

Bab 34 — Database Relasional

Data yang saling berhubungan (siswa–kelas, penulis–buku) butuh relasi antar tabel.

34.1 Model & Relationship

SQLAlchemy punya 3 jenis relationship utama:

One to ManySatu Kelas punya banyak Siswa. db.relationship() + ForeignKey.
Many to ManySiswa punya banyak Ekstrakurikuler, dan sebaliknya. Butuh tabel asosiasi.
One to OneSatu User punya satu Profil. Pakai uselist=False.
models.py
class Kelas(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    nama = db.Column(db.String(50))
    siswa = db.relationship("Siswa", backref="kelas")

class Siswa(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    nama = db.Column(db.String(50))
    kelas_id = db.Column(db.Integer, db.ForeignKey("kelas.id"))
💡 Dengan relasi, kamu bisa akses kelas.siswa (list siswa) atau siswa.kelas (objek kelas) — tanpa perlu query manual!

34.2 Query Lanjutan

Query yang sering dipakai:

  • Model.query.all() — semua data.
  • Model.query.filter_by(kolom=nilai).all() — filter sederhana.
  • Model.query.filter(Model.kolom > 10).all() — filter lanjutan.
  • Model.query.order_by(Model.kolom).all() — urutkan.
  • Model.query.first() — ambil satu data pertama.
  • Model.query.count() — hitung jumlah.
query.py
# Semua siswa di kelas XI IPA 2
kelas = Kelas.query.filter_by(nama="XI IPA 2").first()
for s in kelas.siswa:
    print(s.nama)

Bab 35 — CRUD Lengkap

Setelah paham Create-Read-Update-Delete, kita lengkapi dengan redirect, flash message, dan validasi.

35.1 CRUD + Redirect

Pola CRUD modern di Flask:

crud.py
@app.route("/buku/tambah", methods=["GET", "POST"])
def tambah_buku():
    if request.method == "POST":
        judul = request.form["judul"]
        buku_baru = Buku(judul=judul)
        db.session.add(buku_baru)
        db.session.commit()
        flash("Buku berhasil ditambahkan!")
        return redirect(url_for("list_buku"))
    return render_template("tambah_buku.html")

Perhatikan: setelah POST, kita redirect (bukan render) supaya user tidak bisa refresh dan double submit.

35.2 Flash Messages

Flash message adalah notifikasi sekali tampil yang bisa muncul di halaman berikutnya.

app.py
from flask import flash

# Kirim pesan:
flash("Data berhasil disimpan!", "success")

# Di template:
{% with messages = get_flashed_messages(with_categories=true) %}
  {% for category, message in messages %}
    <div class="alert alert-{{ category }}">{{ message }}</div>
  {% endfor %}
{% endwith %}

Bab 36 — Upload File & Gambar

Hampir semua aplikasi modern punya fitur upload — foto profil, dokumen, gambar produk. Yuk pelajari!

36.1 Upload Gambar

Flask menerima file dari form lewat request.files. File disimpan dengan file.save(path).

upload.py
import os
from werkzeug.utils import secure_filename

UPLOAD_FOLDER = "static/uploads"
app.config["UPLOAD_FOLDER"] = UPLOAD_FOLDER

@app.route("/upload", methods=["GET", "POST"])
def upload():
    if request.method == "POST":
        file = request.files["foto"]
        if file.filename != "":
            filename = secure_filename(file.filename)
            file.save(os.path.join(UPLOAD_FOLDER, filename))
            return f"File {filename} berhasil diupload!"
    return "Kirim file lewat form."

36.2 Validasi File

Jangan pernah percaya file dari user! Selalu validasi:

  • Ekstensi — hanya izinkan .jpg, .png, .gif.
  • Ukuran — batasi maksimal 2 MB.
  • Nama file — gunakan secure_filename() untuk mencegah path traversal.
  • Konten — verifikasi file benar-benar gambar (bukan script berbahaya).
validasi.py
ALLOWED = {"png", "jpg", "jpeg", "gif"}

def allowed_file(filename):
    return "." in filename and \
        filename.rsplit(".", 1)[1].lower() in ALLOWED
Catatan tutor: Bahaya keamanan yang paling sering terjadi adalah path traversal — user mengirim nama file seperti ../../etc/passwd. secure_filename() mencegah ini!
