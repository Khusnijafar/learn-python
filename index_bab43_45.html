Bab 43 — Introduction to AI & Machine Learning

Kecerdasan Buatan (AI) bukan sihir — ia adalah cabang ilmu komputer yang membuat mesin bisa belajar dari data. Di bab ini, kamu akan memahami konsep dasarnya dan mencoba melatih model pertama.

43.1 Apa itu AI, ML, dan DL?

Tiga istilah ini sering tertukar. Mari kita pilah dengan analogi sederhana.

🧠
AI (Artificial Intelligence)LUAS Payung besar: semua usaha membuat mesin "berpikir" seperti manusia — termasuk aturan sederhana seperti if nilai > 75: lulus.
📊
ML (Machine Learning)DATA Cabang AI: mesin belajar dari data tanpa diprogram eksplisit. Kamu memberi contoh, ia menemukan polanya.
🕸️
DL (Deep Learning)NEURAL Cabang ML: menggunakan jaringan saraf tiruan berlapis-lapis. Dasar dari ChatGPT, image recognition, dan mobil otonom.

Analogi: AI adalah "kendaraan", ML adalah "mobil", dan DL adalah "mobil sport". Semua mobil sport adalah mobil, semua mobil adalah kendaraan — tapi tidak semua kendaraan adalah mobil.

Cara berpikir baru: Pemrograman tradisional = kamu menulis aturan (if, for, dst). Machine Learning = kamu memberi data + jawaban, dan mesin menemukan aturannya sendiri.

43.2 Jenis-jenis Machine Learning

🎯 Supervised Learning Belajar dari data berlabel. Contoh: gambar kucing/dog yang sudah ditandai, harga rumah beserta harganya. Algoritma: Linear Regression, Decision Tree, Neural Network.
🔍 Unsupervised Learning Belajar dari data tanpa label. Mencari pola tersembunyi. Contoh: segmentasi pelanggan. Algoritma: K-Means, PCA.
🎮 Reinforcement Learning Belajar melalui trial & error dengan reward/penalti. Contoh: AI bermain game, robot berjalan. Algoritma: Q-Learning, DQN.
🏷️ Klasifikasi vs Regresi Klasifikasi: memprediksi kategori (spam/bukan). Regresi: memprediksi angka (harga, suhu).

Alur kerja Machine Learning secara umum:

  1. Kumpulkan DataContoh-contoh nyata
  2. Pilih ModelAlgoritma yang cocok
  3. Latih (Training)Model belajar pola
  4. Evaluasi & PrediksiUji dengan data baru

43.4 Kode: Melatih Model dengan scikit-learn

Di Python asli, kamu bisa melatih Linear Regression hanya dengan 3 baris!

linear_regression.py
from sklearn.linear_model import LinearRegression
import numpy as np

# Data: jam belajar (X) vs nilai ujian (y)
X = np.array([[1], [2], [3], [4], [5], [6], [7], [8]])
y = np.array([50, 55, 62, 68, 72, 78, 82, 88])

# Latih model
model = LinearRegression()
model.fit(X, y)

# Prediksi nilai jika belajar 10 jam
print(f"Belajar 10 jam → prediksi {model.predict([[10]])[0]:.1f}")
print(f"Slope: {model.coef_[0]:.2f}")
print(f"Intercept: {model.intercept_:.2f}")

Analogi hasilnya: model menemukan garis y = 5.4x + 44.3. Artinya, setiap tambahan 1 jam belajar, nilai naik sekitar 5.4 poin.

44.2 Board dengan NumPy

Repositori papan Tic Tac Toe yang rapi:

board.py
import numpy as np

# Konstanta
EMPTY, X, O = 0, 1, 2

def new_board():
    return np.zeros((3, 3), dtype=int)

def winner(board):
    """Cek pemenang. Return 1/2 atau 0 kalau belum ada."""
    # Cek baris dan kolom
    for i in range(3):
        if all(board[i, :] == board[i, 0]) and board[i, 0] != EMPTY:
            return board[i, 0]
        if all(board[:, i] == board[0, i]) and board[0, i] != EMPTY:
            return board[0, i]
    # Diagonal
    if board[0,0] == board[1,1] == board[2,2] != EMPTY: return board[0,0]
    if board[0,2] == board[1,1] == board[2,0] != EMPTY: return board[0,2]
    return 0

def empty_cells(board):
    """Return list (row, col) yang masih kosong."""
    return [(r, c) for r in range(3) for c in range(3) if board[r, c] == EMPTY]
💡 Perhatikan trik NumPy: board[i, :] mengambil satu baris penuh, all(...) cek apakah semua elemen sama — tidak perlu loop manual!

44.3 Algoritma Minimax — Otak Si AI

Minimax adalah algoritma pencarian yang menganggap AI dan lawan bermain sempurna. Prinsipnya sederhana:

  1. AI memaksimalkanskor (menang = +1)
  2. Lawan meminimalkanskor (kalah = -1)
  3. Rekursifcoba semua langkah masa depan
  4. Pilihlangkah dengan skor terbaik

Pohon pencarian: dari papan kosong, ada 9 kemungkinan langkah pertama. Setelah itu 8, 7, 6… sampai selesai. Total ±255.168 kemungkinan — kecil untuk komputer modern, tapi sangat besar untuk manusia!

minimax.py
def minimax(board, depth, is_maximizing, ai_player):
    """Return skor terbaik dari posisi ini."""
    w = winner(board)
    if w == ai_player:  return 10 - depth    # menang (makin cepat makin baik)
    if w != 0:            return depth - 10     # kalah
    if len(empty_cells(board)) == 0: return 0  # seri

    if is_maximizing:
        best = -inf
        for r, c in empty_cells(board):
            board[r, c] = ai_player
            score = minimax(board, depth+1, False, ai_player)
            board[r, c] = 0  # undo
            best = max(best, score)
        return best
    else:
        best = +inf
        opponent = 3 - ai_player
        for r, c in empty_cells(board):
            board[r, c] = opponent
            score = minimax(board, depth+1, True, ai_player)
            board[r, c] = 0
            best = min(best, score)
        return best
Kenapa tidak pernah kalah? Minimax mencoba semua kemungkinan. Selama papan Tic Tac Toe bisa diselesaikan, AI akan selalu menemukan langkah terbaik — dan hasil terburuknya adalah seri.

44.5 Kode Lengkap (Jalankan di Laptopmu)

Simpan sebagai tictactoe.py lalu jalankan python tictactoe.py:

tictactoe.py
import numpy as np

EMPTY, X, O = 0, 1, 2

def display(board):
    symbols = {0: ".", 1: "X", 2: "O"}
    for row in board:
        print(" ".join(symbols[v] for v in row))

def winner(b):
    for i in range(3):
        if b[i,0] == b[i,1] == b[i,2] != 0: return b[i,0]
        if b[0,i] == b[1,i] == b[2,i] != 0: return b[0,i]
    if b[0,0] == b[1,1] == b[2,2] != 0: return b[0,0]
    if b[0,2] == b[1,1] == b[2,0] != 0: return b[0,2]
    return 0

def empty_cells(b):
    return [(r,c) for r in range(3) for c in range(3) if b[r,c]==0]

def minimax(b, depth, maxing, ai):
    w = winner(b)
    if w == ai: return 10 - depth
    if w != 0: return depth - 10
    cells = empty_cells(b)
    if not cells: return 0
    scores = []
    for r,c in cells:
        b[r,c] = ai if maxing else 3-ai
        s = minimax(b, depth+1, not maxing, ai)
        b[r,c] = 0
        scores.append(s)
    return max(scores) if maxing else min(scores)

def best_move(b, ai):
    cells = empty_cells(b)
    best_score, best = -inf, cells[0]
    for r,c in cells:
        b[r,c] = ai
        s = minimax(b, 0, False, ai)
        b[r,c] = 0
        if s > best_score:
            best_score, best = s, (r,c)
    return best

# --- Game loop ---
board = np.zeros((3,3), dtype=int)
while True:
    display(board)
    w = winner(board)
    if w: print("Pemenang: " + ("X" if w==1 else "O")); break
    if not empty_cells(board): print("Seri!"); break
    r, c = map(int, input("Baris kolom (0-2): ").split())
    if board[r,c] == 0: board[r,c] = X
    if winner(board) or not empty_cells(board): continue
    r, c = best_move(board, O)
    board[r,c] = O

Bab 45 — OpenCV Image Manipulation

Computer Vision adalah cabang AI yang membuat komputer "melihat". OpenCV adalah library nomor satu untuk itu. Di bab ini, kamu akan mengolah gambar — sama seperti yang dilakukan filter Instagram, mobil otonom, dan kamera pengawas.

45.1 Kenalan OpenCV

OpenCV (Open Source Computer Vision) adalah library open-source yang berisi ribuan fungsi untuk mengolah gambar dan video. Dipakai oleh Google, Intel, NASA, dan ribuan perusahaan.

🖼️ Image ProcessingResize, crop, rotate, filter, blur, threshold — manipulasi pixel.
🎯 Object DetectionMendeteksi wajah, mobil, plat nomor, produk.
🎥 Video AnalysisTracking objek, motion detection, counting.
🤖 ML IntegrationBekerja bareng TensorFlow/PyTorch untuk deep learning.

45.2 Operasi Dasar Gambar

Resize, crop, rotate, dan flip — empat operasi yang paling sering dipakai:

basic_ops.py
import cv2

img = cv2.imread("gambar.jpg")

# 1. Resize (skala atau ukuran absolut)
kecil = cv2.resize(img, None, fx=0.5, fy=0.5)  # setengah ukuran
besar = cv2.resize(img, (800, 600))                        # lebar, tinggi

# 2. Crop (slicing seperti NumPy!)
crop = img[100:300, 200:500]  # [y1:y2, x1:x2]

# 3. Rotate 90° searah jarum jam
rot90 = cv2.rotate(img, cv2.ROTATE_90_CLOCKWISE)

# 4. Flip horizontal (mirror)
flip = cv2.flip(img, 1)  # 1=horizontal, 0=vertical, -1=keduanya

# 5. Konversi ke grayscale
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
print(gray.shape)  # (tinggi, lebar) — tanpa channel warna!
💡 Grayscale itu penting untuk ML: gambar berwarna 3 channel (BGR) butuh 3× lebih banyak memori dan komputasi. Untuk deteksi tepi dan pengenalan pola, hitam-putih sudah cukup.

45.4 Filter, Blur & Edge Detection

Blur (Gaussian Blur) — melembutkan gambar dengan merata-ratakan pixel bertetangga. Berguna untuk mengurangi noise sebelum deteksi tepi.

blur.py
# Kernel 5×5 — semakin besar, semakin blur
blur = cv2.GaussianBlur(img, (5, 5), 0)

Threshold — mengubah grayscale jadi hitam-putih murni. Semua pixel di atas nilai tertentu jadi putih, di bawahnya jadi hitam.

threshold.py
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
_, binary = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)

Edge Detection (Canny) — mendeteksi "tepi" objek. Dasar dari pengenalan wajah, OCR, dan self-driving car.

edge.py
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
edges = cv2.Canny(gray, 100, 200)

# 100 = ambang bawah, 200 = ambang atas
# Pixel dianggap "tepi" jika gradiennya di antara keduanya
