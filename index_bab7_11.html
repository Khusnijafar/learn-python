Bab 7 — Variable in Python

Sekarang kita belajar cara nyimpen nilai supaya bisa dipakai berkali-kali tanpa nulis ulang — kenalan sama variable, yuk!

7.1 Variable in Python

Variable itu kayak kotak penyimpanan yang punya nama (label), isinya bisa berupa teks, angka, dan lain-lain. Sekali kamu simpan sesuatu ke dalam variable, kamu bisa pakai lagi nilainya kapan pun cukup dengan manggil namanya.

Kenapa variable penting?

  • Kode jadi lebih fleksibel — tinggal ganti isi variable-nya, nggak perlu ubah kode di banyak tempat.
  • Nggak perlu nulis ulang nilai yang sama berkali-kali.
  • Bikin kode lebih gampang dibaca, karena nama variable bisa menjelaskan isinya.
Catatan tutor: analoginya kayak toples berlabel di dapur — toples berlabel "gula" isinya bisa diganti-ganti, tapi labelnya tetap sama supaya gampang dicari.

7.2 How to Use Variable

Cara membuat variable gampang banget — tinggal tulis nama variable-nya, tanda sama dengan =, terus nilainya. Tanda = di sini artinya "memberi nilai", bukan "sama dengan" kayak di matematika!

variable.py
nama = "Siti"
umur = 15
print(nama)
print(umur)
# Hasil: Siti lalu 15
variable.py
OUTPUT

7.3 Rules in Typing Variables

  • Harus diawali huruf atau underscore _ — tidak boleh diawali angka.
  • Setelah huruf pertama, boleh mengandung huruf, angka, atau underscore.
  • Tidak boleh ada spasi — pakai underscore.
  • Case-sensitive — nama dan Nama beda.
  • Tidak boleh pakai kata kunci Python seperti print, input, if, for.

Bab 9 — Python Data Types

Setiap nilai di Python punya tipe data. Yuk kenali tipe-tipe dasar dan cara mengubahnya.

9.1 Penjelasan Data Types

Python memiliki beberapa tipe data bawaan yang sering dipakai:

  • int — bilangan bulat, contoh: 10, -3, 0
  • float — bilangan desimal, contoh: 3.14, -0.5, 2.0
  • str — teks/string, contoh: "Halo", 'Python'
  • bool — nilai kebenaran: True atau False
  • list — kumpulan nilai berurutan, contoh: [1, 2, 3]
  • tuple — seperti list tapi tidak bisa diubah, contoh: (1, 2, 3)
  • dict — pasangan kunci-nilai, contoh: {"nama": "Siti", "umur": 15}
  • set — kumpulan nilai unik, contoh: {1, 2, 3}
💡 Tipe data menentukan operasi apa yang bisa dilakukan pada nilai tersebut. Misalnya, kamu bisa menjumlahkan dua angka, tapi tidak bisa menjumlahkan angka dengan teks secara langsung.

9.3 Data Types Conversion

Kadang kita perlu mengubah suatu nilai dari satu tipe ke tipe lain. Python menyediakan fungsi-fungsi konversi:

  • int(x) — mengubah x menjadi integer (bulat)
  • float(x) — mengubah x menjadi float (desimal)
  • str(x) — mengubah x menjadi string (teks)
  • bool(x) — mengubah x menjadi boolean (True/False)
  • list(x) — mengubah x menjadi list
  • tuple(x) — mengubah x menjadi tuple
konversi.py
angka = "123"
print(int(angka) + 10)  # 133
print(float(angka))       # 123.0
print(bool(0))            # False
print(list("Python"))    # ['P', 'y', 't', 'h', 'o', 'n']

Bab 10 — List in Python

List adalah kumpulan nilai yang bisa diubah-ubah. Sangat berguna untuk menyimpan banyak data sekaligus.

10.1 List Explanation

List adalah tipe data yang bisa menampung banyak nilai (bisa berbagai tipe) dalam satu variable. List dibuat dengan tanda kurung siku [ ] dan nilai-nilainya dipisahkan koma.

list.py
buah = ["apel", "pisang", "mangga"]
nilai = [90, 85, 78, 92]
campuran = ["Andi", 17, "SMA", True]

List bisa diakses indeksnya dimulai dari 0:

list.py
buah = ["apel", "pisang", "mangga"]
print(buah[0])  # apel
print(buah[2])  # mangga
print(buah[-1]) # mangga (indeks negatif dari belakang)
Catatan tutor: List itu mutable — artinya isinya bisa diubah setelah dibuat. Kamu bisa menambah, menghapus, atau mengganti elemen di dalam list.

10.2 How to use & List Rules in Python

Beberapa operasi penting pada list:

  • append(x) — menambah x di akhir list
  • insert(i, x) — menyisipkan x pada indeks i
  • remove(x) — menghapus elemen pertama yang bernilai x
  • pop(i) — menghapus elemen pada indeks i (jika tanpa i, hapus elemen terakhir)
  • len(list) — mengembalikan jumlah elemen
  • index(x) — mengembalikan indeks pertama kemunculan x
  • sort() — mengurutkan list (untuk tipe yang sebanding)
  • reverse() — membalik urutan list
list_ops.py
warna = ["merah", "kuning"]
warna.append("hijau")
print(warna)  # ['merah', 'kuning', 'hijau']
warna.insert(1, "biru")
print(warna)  # ['merah', 'biru', 'kuning', 'hijau']
warna.remove("kuning")
print(warna)  # ['merah', 'biru', 'hijau']
print(len(warna)) # 3
💡 List bisa berisi berbagai tipe data, bahkan list di dalam list (list bersarang).

Bab 11 — Python Turtle

Turtle adalah cara seru untuk belajar pemrograman dengan menggambar. Kita akan menggerakkan "kura-kura" di layar menggunakan perintah Python.

11.1 Python Turtle

Module turtle adalah bagian dari library standar Python. Dengan turtle, kamu bisa menggambar berbagai bentuk dengan menggerakkan kursor seperti pena.

Konsep dasar: kura-kura bergerak di atas kanvas, meninggalkan jejak (jika pena diturunkan) atau tidak (jika pena diangkat). Kamu bisa mengatur warna, ukuran pena, kecepatan, dan banyak lagi.

Catatan tutor: Di modul ini, kita menggunakan simulator turtle berbasis canvas. Semua perintah dasar turtle tersedia dan hasilnya langsung terlihat.

11.2 Python Turtle Methods

Berikut metode-metode utama turtle:

  • forward(jarak) — maju sejauh jarak
  • backward(jarak) — mundur
  • left(sudut) — belok kiri (derajat)
  • right(sudut) — belok kanan
  • penup() — angkat pena (tidak meninggalkan jejak)
  • pendown() — turunkan pena
  • color(warna) — ubah warna pena (contoh: "red", "blue", "green", "#FF0000")
  • pensize(ukuran) — ubah ketebalan pena
  • circle(jari_jari) — gambar lingkaran
  • begin_fill() — mulai mengisi area
  • end_fill() — selesai mengisi area
  • goto(x, y) — pindah ke koordinat (x, y)
  • setheading(derajat) — arahkan ke sudut tertentu (0 = timur, 90 = utara)
  • speed(kecepatan) — kecepatan (0–10, 0 = tercepat)
  • clear() — hapus semua gambar
  • home() — kembali ke posisi awal (0,0) menghadap timur
💡 Coba kombinasi perintah untuk membuat gambar yang keren! Misalnya: forward(100); left(90); forward(100); left(90); ... untuk buat persegi.
